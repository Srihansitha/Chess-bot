# Chess Bot

A Python-based Chess Bot that implements chess gameplay, move validation,
piece movement, capturing, and automated decision-making.

## Features

- Interactive chess board
- Legal move validation
- Piece movement and capturing
- Automated chess moves
- Chess game logic
- Support for special chess moves such as castling

## Technologies Used

- Python
- Jupyter Notebook
- Object-Oriented Programming
- Game Search Algorithms
